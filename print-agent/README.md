# Sapo Direct Print Agent (Windows)

See `../PRINT-AGENT-HUONG-DAN.md` for full setup.

Quick start:
1. Install Node.js 20+.
2. Run `setup.ps1` in PowerShell to create `config.json`.
3. Run `npm install`.
4. Run `npm start`.

The agent uses Windows Print Spooler and the installed printer driver. It has no print queue. Keep the Agent running while you need to print.
